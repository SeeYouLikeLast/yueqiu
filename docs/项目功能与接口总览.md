# 项目功能与接口总览

所有前端请求使用 `/api` 前缀；Vite/Nginx 会移除该前缀转发到 Spring Boot。除特别说明外，响应均为：

```json
{ "code": 0, "message": "ok", "data": {} }
```

需要登录的接口携带 `Authorization: Bearer <token>`。城市上下文使用 URI 编码后的 `X-Location-City` 请求头；后端依次回退 Token 城市和默认西安。

## 1. 认证与资料

| 方法 | 路径 | 登录 | 说明 |
| --- | --- | --- | --- |
| POST | `/auth/register` | 否 | 账号注册并返回登录态 |
| POST | `/auth/code` | 否 | 发送邮箱验证码；60 秒冷却、10 分钟最多 5 次、5 分钟过期 |
| POST | `/auth/login` | 否 | 邮箱验证码登录/自动注册或账号密码登录 |
| GET | `/auth/me` | 是 | 当前账号与资料 |
| PUT | `/auth/me` | 是 | 更新个人资料 |
| PUT | `/auth/location` | 是 | 保存确认后的城市、地址、经纬度并刷新登录态 |
| GET | `/auth/users/{id}` | 否 | 用户公开主页 |

## 2. 目录、定位与真实场所

| 方法 | 路径 | 登录 | 说明 |
| --- | --- | --- | --- |
| GET | `/sports` | 否 | 球类目录，Redis 缓存 24 小时 |
| GET | `/categories/{type}` | 否 | `type=1` 场所商品分类；`type=2` 装备分类 |
| GET | `/places/nearby` | 否 | 高德附近场所；必填 `lng`、`lat`，可选 `sport/keyword/radius/page/size` |
| GET | `/places/regeo` | 否 | 坐标逆地理编码 |
| GET | `/places/ip-location` | 否 | 浏览器定位失败时的 IP 城市级兜底 |

附近场所查询会自动扩大半径、按 POI 去重，并短暂缓存高德结果。定位优先级为 HTTPS 浏览器高精度定位、IP 城市级定位、默认西安。

## 3. 场所商品、装备与评价

| 方法 | 路径 | 登录 | 说明 |
| --- | --- | --- | --- |
| GET | `/items/1` | 否 | 场所商品；支持 `sport/amapPlaceId/venueId/placeRank/category/keyword/page/size/limit` |
| GET | `/items/1/{id}` | 否 | 场所商品详情 |
| GET | `/items/1/{id}/inventories` | 否 | 指定场所商品未来库存，可选 `date` |
| GET | `/items/2` | 否 | 装备列表；支持 `sport/categoryId/keyword/page/size` |
| GET | `/items/2/{id}` | 否 | 装备详情 |
| GET | `/venues/reviews/{sport}/{placeRank}` | 否 | 当前城市指定球类第 N 个高德场所的评价；可选 `page/size` |

`place` 是真实高德场所，`venue` 是挂载在场所顺序上的可售团购/单场/私教商品。库存不直接作为前端下单依据，下单时由后端再次校验。

## 4. 购物车、支付、订单与秒杀

`type=1` 代表场所商品，`type=2` 代表装备。

| 方法 | 路径 | 登录 | 说明 |
| --- | --- | --- | --- |
| POST | `/cart` | 是 | 加入购物车，传 `type/productId/inventoryId/quantity` |
| GET | `/cart` | 是 | 当前用户全部购物车项 |
| PATCH | `/cart/{type}/{itemId}` | 是 | 修改数量 |
| DELETE | `/cart/{type}/{itemId}` | 是 | 删除购物车项 |
| POST | `/payments` | 是 | 直接创建并支付订单 |
| POST | `/payments/cart` | 是 | 购物车结算并支付 |
| GET | `/orders/{type}` | 是 | 对应普通订单与秒杀订单的合并展示 |
| GET | `/seckill/{type}` | 否 | 秒杀活动，支持 `sport/categoryId` |
| POST | `/seckill/{type}/{seckillId}` | 是 | 提交秒杀请求 |

普通支付在 Service 层事务中完成“创建订单 + 支付”。秒杀使用 Redis Lua 原子预扣、Redisson 分布式锁、数据库唯一约束；有 MQ 时异步落库，轻量模式会同步补偿。

## 5. 社区、关注与 Feed

| 方法 | 路径 | 登录 | 说明 |
| --- | --- | --- | --- |
| GET | `/blogs` | 否 | 推荐/球类频道；支持 `channel/sport/keyword/page/size` |
| GET | `/blogs/of/user/{userId}` | 否 | 某用户公开动态 |
| GET | `/blogs/of/follow` | 是 | 关注流；滚动参数 `lastId/offset` |
| GET | `/blogs/{id}` | 否 | 博客详情 |
| POST | `/blogs` | 是 | 发布动态，可关联装备或场所商品 |
| DELETE | `/blogs/{id}` | 是 | 逻辑删除自己的动态 |
| PUT | `/blogs/{id}/like` | 是 | 点赞/取消点赞 |
| PUT | `/follows/{id}/{follow}` | 是 | 关注或取消关注作者 |

普通作者采用推模式写入粉丝 Feed；大 V 采用拉模式读取 outbox，关注流使用 `maxTime + offset` 处理同一时间戳的分页。

## 6. 球友、约球与一键购买发起

| 方法 | 路径 | 登录 | 说明 |
| --- | --- | --- | --- |
| GET | `/social/players` | 否 | 同城球友；支持 `sport/area/level/lng/lat/page/size` |
| GET | `/social/profile/me` | 是 | 我的球友资料 |
| POST | `/social/profile/me` | 是 | 保存球友资料 |
| GET | `/social/activities` | 否 | 约球列表；支持 `sport/level/scope/page/size`，`scope=created/others/joined` |
| POST | `/social/activities` | 是 | 发起约球活动 |
| POST | `/social/activities/{id}/join` | 是 | 加入活动 |
| POST | `/social/activities/book-and-create` | 是 | 用户确认后购买场所时段并在同时间创建活动 |

活动创建校验开始/结束时间；加入活动通过条件更新限制人数，排除本人创建和已加入的活动。

## 8. AI 助手

| 方法 | 路径 | 登录 | 说明 |
| --- | --- | --- | --- |
| GET | `/agent/status` | 否 | DashScope 是否可用 |
| POST | `/agent/chat` | 否 | 同步聊天，返回回答、真实业务卡片、快捷追问和会话 id |
| POST | `/agent/chat/stream` | 否 | SSE 流式进度与最终回答，当前前端主入口 |
| GET | `/agent/conversations` | 否 | 登录用户查 MySQL 历史；游客凭匿名 Cookie 查 Redis 历史 |
| GET | `/agent/conversations/{id}/messages` | 否 | 校验账号或匿名 Cookie 归属后查询会话消息 |
| DELETE | `/agent/conversations/{id}` | 否 | 登录用户软删除；游客删除自己的 Redis 会话 |

AI 先用真实工具获取硬事实，再用实体约束 RAG 补充博客、评价和装备心得，并通过统一评分和 `cardId` 校验选择候选。打开场所、加入购物车、加入活动、购买、支付仍由前端按钮调用原业务接口并二次确认。

## 9. 返回与错误约定

- `code=0`：成功。
- `401`：未登录或登录态过期，前端提示后跳转登录页。
- `409`：重复抢购、库存不足、人数已满等冲突。
- `429`：AI 请求频率超过限流。
- `5xx`：第三方高德、DashScope、对象存储或应用内部异常；前端显示可读提示，不解析 HTML 错误页。
