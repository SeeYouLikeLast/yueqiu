# 生产部署、安全、运维与测试

## 1. 部署拓扑

```text
Internet :443
  -> Nginx
     -> /               Vue dist
     -> /api            Spring Boot 127.0.0.1:8088
     -> /objects        MinIO 127.0.0.1:9000

Spring Boot
  -> MySQL 127.0.0.1:3307
  -> Redis 127.0.0.1:6379
  -> RocketMQ 127.0.0.1:9876/10911（完整模式）
```

3306/3307、6379、9000/9001、9876、10911 不在 ECS 安全组对公网开放。公网只允许 22（限管理 IP）、80 和 443。

## 2. 环境配置

生产使用 `/etc/hm-badminton/app.env`，必须包含：

- `SPRING_PROFILES_ACTIVE=prod` 或 `prod,lite`。
- MySQL URL/用户名/密码。
- Redis 主机/端口。
- MinIO endpoint/access key/secret key/bucket。
- `JWT_SECRET`、`AMAP_KEY`、DashScope API Key、SMTP 授权码。
- ECS 内存较小时的 `JAVA_TOOL_OPTIONS=-Xms128m -Xmx384m`。

Git 只提交 `.env.example`，真实 `.env` 永不提交。

## 3. profile 差异

| profile | SQL 初始化 | RocketMQ | 用途 |
| --- | --- | --- | --- |
| 默认开发 | `schema.sql + data.sql` | 默认开 | 本地反复演示 |
| `prod` | `never` | 开 | 完整生产链路 |
| `prod,lite` | `never` | 关，同步降级 | 2GB ECS 轻量演示 |

生产重启不会自动重建 MySQL 或 MinIO。演示数据只能在明确确认后手工执行初始化脚本。

## 4. HTTPS

- Nginx 443 使用证书处理 TLS。
- 80 只用于跳转 HTTPS。
- Spring Boot 通过 `X-Forwarded-Proto` 和 `forward-headers-strategy=framework` 识别原始安全请求。
- IP 证书必须在 SAN 中包含公网 IP；更推荐域名 + 可信 CA 证书。

## 5. 资源与鲁棒性

- 2GB ECS 建议创建 swap，但 swap 不是内存升级的替代品。
- Docker Compose 对 MySQL、Redis、MinIO 设内存限制和 healthcheck。
- 轻量模式不启 RocketMQ；内存足够时可启用完整异步链路。
- 前后端日志在每次启动前截断，生产建议改用 logrotate/systemd journal 保留有限周期。

## 6. 备份

- MySQL：定期 `mysqldump`，并在独立环境验证恢复。
- MinIO：备份 bucket 对象和配置，数据库元数据与对象必须一起恢复。
- Redis：可按需启用 AOF/RDB；缓存可重建，但登录态和未落库秒杀状态需评估。
- 配置：安全备份 Nginx、systemd 和环境变量文件，不进 Git。

## 7. 自动化测试

| 层次 | 命令/工具 | 目标 |
| --- | --- | --- |
| 后端单元/集成 | `mvn test` | Service、Mapper、接口回归 |
| 后端构建 | `mvn clean package` | Java 编译和可部署 JAR |
| 前端类型 | `npm run type-check` | TypeScript 契约 |
| 前端构建 | `npm run build` | Vite 生产产物 |
| API 基准 | `scripts/test-api-performance.ps1` | 正确性、平均/P95 耗时 |
| 秒杀并发 | JMeter `.jmx` | 吞吐、P95/P99、错误率、一人一单 |

JMeter 输出 `.jtl` 和 HTML 报告不提交 Git，测试脚本和结论才提交。压测前必须用独立测试活动/数据，不对公网生产演示数据盲目施压。

## 8. 监控建议

- HTTP QPS、错误率、P95/P99。
- JVM heap、GC、线程/虚拟线程、Hikari 连接池。
- MySQL 慢查询和锁等待。
- Redis 命中率、内存、big key/hot key。
- RocketMQ 生产失败、消费延迟、重试和死信。
- 高德、DashScope、MinIO 耗时和失败率。
