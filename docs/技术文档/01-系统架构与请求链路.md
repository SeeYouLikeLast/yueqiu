# 系统架构与请求链路

## 1. 功能边界

约个球是 B/S 架构的移动端 Web 应用。Vue 负责交互，Spring Boot 负责业务，MySQL 保存持久化事实，Redis 保存登录态、缓存和并发状态，MinIO 保存文件本体，RocketMQ 用于秒杀订单异步落库。

## 2. 技术栈

| 层次 | 技术 | 职责 |
| --- | --- | --- |
| 前端 | Vue 3、TypeScript、Vite | 页面、状态和移动端交互 |
| 网关 | Nginx | HTTPS 终止、静态文件、`/api`、`/objects` 反向代理 |
| Web | Spring Boot 3、Spring MVC、Validation | HTTP 接口、校验、异常处理 |
| 业务 | Service 接口 + `impl` | 业务编排和事务边界 |
| 数据 | MyBatis-Plus + Mapper | CRUD、条件更新、联表查询 |
| 缓存 | Redis、Redisson、Lua | 登录态、缓存、分布式锁、原子预扣 |
| 消息 | RocketMQ | 秒杀削峰和异步订单 |
| 对象存储 | MinIO | 头像和用户上传图片 |
| AI | Spring AI Alibaba、DashScope、Graph、RAG | 意图提取、工具查询和推荐解释 |

## 3. 开发环境请求链

```text
Browser -> http://localhost:5173/api/...
        -> Vite proxy 去掉 /api
        -> http://localhost:8088/...
        -> Controller -> Service -> Mapper/Redis/外部 API
```

`frontend/src/api/client.ts` 统一使用 `API_BASE = '/api'`，页面不写后端主机和端口。

## 4. 生产环境请求链

```text
Browser --HTTPS:443--> Nginx
  /                 -> /var/www/hm-badminton
  /api/*            -> HTTP 127.0.0.1:8088
  /objects/*        -> HTTP 127.0.0.1:9000
```

HTTPS 只在浏览器到 Nginx 之间使用。Nginx 到同一台 ECS 内的 Spring Boot/MinIO 使用回环 HTTP，端口不对公网开放。

## 5. 后端分层

```text
controller -> service -> service/impl -> mapper -> MySQL
                       -> CacheClient -> Redis
                       -> MinIO / AMap / DashScope / RocketMQ
```

- Controller 只解析 HTTP 参数和返回 `ApiResponse<T>`。
- Service 接口定义业务能力，`impl` 承担事务和跨 Mapper 编排。
- Mapper 只处理数据访问，不包含 HTTP 和前端逻辑。
- DTO 是请求/响应契约，Entity 对应持久化概念，VO 面向页面展示。

## 6. 认证拦截顺序

1. `RefreshTokenInterceptor` 拦截所有请求，有 token 时从 Redis 恢复用户并续期。
2. `LoginInterceptor` 只拦截受保护接口，检查 `UserContext`。
3. Controller/Service 通过 `UserContext` 取得当前用户。
4. 请求结束后清理 ThreadLocal，避免线程复用串号。

## 7. 统一响应和异常

- 普通接口返回 `ApiResponse<T>`：`code` + `message` + `data`。
- 分页使用 `PageResult<T>`。
- Feed 使用 `ScrollResult<T>`。
- `BusinessException` 承载可预期业务错误，`GlobalExceptionHandler` 统一转换为 JSON。
- AI 流式接口使用 `text/event-stream`，不包在普通 JSON 响应中。
