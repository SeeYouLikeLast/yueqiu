## 阅读一个复杂方法的固定步骤

1. 先把方法签名翻译成一句中文，明确输入和返回值。
2. 只看 `// 1.` 到 `// n.` 的步骤标题，先得到流程骨架。
3. 找出哪些步骤只做友好校验，哪些步骤是并发下的最终保护。
4. 标出数据库事务从哪里开始、哪里提交或回滚。
5. 标出 Redis/MQ/MinIO/高德失败时是报错、降级还是补偿。
6. 最后才进入 Mapper 看 SQL，不要一开始陷入字段映射。

完整的模块业务流程见 [新手代码阅读指南](新手代码阅读指南.md)。
