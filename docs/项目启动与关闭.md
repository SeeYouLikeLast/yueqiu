### 启动
在 Windows PowerShell 启动后端：

```powershell
cd D:\Program\java\hm\hm-badminton\backend
mvn spring-boot:run
```

启动前端：

```powershell
cd D:\Program\java\hm\hm-badminton\frontend
npm install
npm run dev
```

访问：

```text
http://localhost:5173
```

```
wsl
```
### 关闭
#### wsl
先在 PowerShell 里看 WSL 状态：

```
wsl -l -v
```

关闭所有 WSL：

```
wsl --shutdown
```

这会把 WSL 里的 Docker、MySQL、Redis、MinIO、RocketMQ 一起停掉。
